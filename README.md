# Calculadora de IMC

Projeto simples de uma calculadora de IMC desenvolvido com o objetivo de praticar conhecimentos em HTML, CSS e JavaScript.

## Sobre o projeto

A aplicação permite que o usuário informe seu peso e altura para calcular o Índice de Massa Corporal (IMC).

Além do cálculo, o projeto foi utilizado para praticar conceitos básicos de desenvolvimento web, como manipulação de elementos da página, eventos e lógica com JavaScript.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Inserção de peso
- Inserção de altura
- Cálculo automático do IMC
- Exibição do resultado
- Classificação do IMC

## Como funciona

O IMC é calculado utilizando a fórmula:

IMC = peso / altura²

Exemplo:

Peso: 80 kg  
Altura: 1,80 m

IMC = 80 / 1,80²

Resultado: 24,69
